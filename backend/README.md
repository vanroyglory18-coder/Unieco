# Unieco Backend

This directory will house the Node.js/Express backend API for Unieco.

## Key Responsibilities

- User authentication and verification (integration with university/student records)
- Location-based group management
- Needs/Offers marketplace endpoints
- Event and business directory APIs
- Messaging (secure & private)
- Admin and moderation tools

## Tech Stack

- Node.js
- Express
- MongoDB/PostgreSQL
- JWT for auth
- Socket.io for real-time features
