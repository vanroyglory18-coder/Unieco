# Unieco Frontend

This directory will house the React application for Unieco.

## Getting Started

- The app will be built with React (and optionally, Next.js or React Native for mobile).
- State management: Redux or Context API.
- Styling: Tailwind CSS, Material UI, or Bootstrap.

## Key Features To Implement

- Authentication and student verification
- Location-based feed and chat/groups
- Needs/Offers marketplace UI
- Events discovery
- Secure chat
